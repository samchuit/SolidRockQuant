# 中证1000 稳健策略研究报告

**日期**: 2026-09-09 · **数据**: 000852.SH（2014-10~2026-09）、512100.SH 中证1000ETF（2016-11~2026-09）、510300.SH、511010.SH 国债ETF、518880.SH 黄金ETF
**引擎**: SolidRockQuant 事件驱动 bar 级回测（A 股规则：T+1、涨跌停、整手、佣金万2.5、卖出印花税 0.05%、过户费、滑点 2bps；信号收盘生成、次日开盘成交）

> ⚠️ **2026-09-11 数字修订**：本报告的旗舰年化（§3/§4.1 的 **11.05%**、汇总的 **10.7%**）**当前不可复现**。
> 用 `test_ma_filter.py` 重跑得 **9.36~9.63%/年、回撤 -24.9%、Sharpe 0.59-0.60、IS 9.3% / OOS 9.1%、8/10 年正收益**；
> 分年差异集中在 2021（+17.1%→+15.9%）、2023（+16.4%→+9.8%）、2026（+7.6%→+5.5%）。
> 疑因报告后（09-10）的全市场/Tushare 抓取覆盖了存储中 510300 的复权因子序列（原报告明确写"510300 因子置 1"），
> 使 300ETF 那条腿的动量信号改变。**引用请用 9.4~9.6%/年，不要引用 10.7%/11.05%。**
> 结论方向不变（跨资产轮动 + 趋势过滤仍是唯一稳健为正的方案），但幅度需下调。

> 结论先行：**在"只做多中证1000单一标的"的框架内不存在稳定盈利策略**——过去十年买入持有年化仅 1.6%、最大回撤 -51%，任何择时都无法把一个长期零收益的标的变成稳定盈利资产。**把中证1000放进跨资产动量轮动框架（1000/300/黄金 + 国债防守 + 趋势过滤）** 是本研究找到的唯一在两个窗口、多组参数、高滑点下都稳健为正的方案：年化 ~9.4-9.6%（修订后）、最大回撤 ~-25%、约 8-9 成年份正收益。

## 1. 数据修复（本研究的前置工作，已固化到本地库）

本地 ETF 数据原 `adj_factor` 为 NaN，导致 **512100.SH 2022-09-05 份额合并（约 1:2.747）在原始价中表现为 +175% 假跳变**，会虚增 2016-2022 全部收益类信号。修复方式：

- `adj_factor = 腾讯后复权收盘 / 原始收盘`，清洗为分段常数（仅保留 >0.5% 跳变）；
- 512100.SH 因子段：合并前 1.0 → 合并后 0.36565 → 三次小额分红（2025-01、2026-01）微调；
- 510300/511010/518880 因子置 1（腾讯对 510300 的 hfq 含 60+ 个伪跳变，弃用；代价是 300ETF 约 1%/年分红不计入，方向保守）；
- 原始价经东财/腾讯/新浪三源交叉验证一致；000852 指数两源一致。

修复脚本：`research/csi1000/fix_etf_adj.py`（幂等，可重复执行）。

## 2. 候选策略族

| 策略 | 文件 | 核心逻辑 |
|---|---|---|
| 单均线择时 | `ma_timing.py` | 复权收盘 > MA(N) 持有 512100，否则切 511010（或空仓） |
| 双均线 | `dual_ma.py` | 快线上穿慢均线持风险资产，下穿切防守 |
| 双动量轮动 | `dual_momentum.py` | 每 rebalance 日在资产池中选 lookback 日动量最高者，须高于国债同期收益才持有，否则回防守；可选 MA 趋势过滤 |
| 波动率目标 | `vol_ma_timing.py` | 均线方向 × min(1, 目标波动/已实现波动) 仓位 |
| 买入持有 | `examples/buy_and_hold.py` | 基准 |

工程要点（两个曾导致结果完全失真的 bug，均已修复）：
1. **腿排序**：引擎按队列顺序撮合并实时校验现金，换仓时必须"卖单先于买单提交"，否则入场腿被整单拒收、策略卡死空仓（2015 年牛市全程空仓即由此导致）；
2. **每日重发目标 + 0.5% 死区自愈**：被拒腿次日自动补单，不依赖状态记忆。

## 4. 压力测试

### 4.1 滑点加压（10bps ≈ 默认 5 倍，全场景重跑）

- MA200_def: 4.41% → **3.49%**（存活）
- MO3_lb60_rb20: 9.53% → **8.82%**（存活）
- MA60_def: 1.41% → **-1.12%**（死亡）；双均线全灭；MA20 全灭。
- 推荐配置（lb80/rb10 + MA200 过滤）：2bps 11.05% → 10bps 10.10% → **15bps（7.5 倍）9.50%**，9.6 年仅 106 笔成交（年均 11 笔），低换手是抗摩擦的核心。

### 4.2 参数敏感性（52 组网格，`stress_sweep.csv`）

- 均线族：ma=20~60 年化 0.7~1.5%（死区），**ma=180~220 平台区 4.5~5.6%**——是平台不是孤峰；
- 三资产动量族：lookback 20~80 与 200 均在 8~13.6% 的宽平台，但 **lb120~160 有凹陷（3.6~4.7%）**——参数面并非处处平滑，建议取 60~80 或 ~200 并保持过滤开启；
- 2 资产（无黄金）版本收益减半：黄金腿在 2019-2026 的贡献显著（见 §6 局限）。

### 4.3 样本内/样本外（IS=前半段，OOS=后半段）

| 配置 | 全期年化 | IS 年化 | OOS 年化 |
|---|---|---|---|
| MO3a_lb80_rb10（无过滤） | 13.6% | 16.2% (2017-21) | 9.9% (2022-26) |
| **MO3a_lb80_rb10+MA200过滤** | 10.7% | 9.5% | **10.8%** |

## 5. 推荐

1. **首选：三资产动量轮动 + 趋势过滤**（`dual_momentum.py`，assets=512100,510300,518880，defensive=511010，lookback=80，rebalance=10，ma_filter=200）
   年化 ~10.7%、回撤 ~-25%、夏普 0.65、9.6 年 106 笔、高滑点下仍 ~9.5-10%。期望收益主要来自"永远持有近期最强的那块资产，弱市退到国债"。
2. **简化替代：MA200+国债择时**（`ma_timing.py`，ma=200）——单参数、年化 3.5~4.4%、回撤 -21%，适合作为理解成本最低的底仓方案。
3. **不要用**：短均线、双均线、纯 2 资产动量、波动率目标（本窗口全部无效或负贡献）。

复现：

```bash
srq backtest run research/csi1000/dual_momentum.py --start 2017-01-01 --end 2026-09-08 \
    --param assets=512100.SH,510300.SH,518880.SH --param defensive=511010.SH \
    --param lookback=80 --param rebalance=10 --param ma_filter=200
.venv/Scripts/python.exe research/csi1000/run_suite.py --stage etf|index|stress
.venv/Scripts/python.exe research/csi1000/stress_sweep.py
```

## 6. 局限与风险（务必阅读）

1. **黄金周期依赖**：轮动策略 2020（+52%）、2025（+67%）的大年由黄金牛市驱动；若黄金转入均值回归，期望收益应下调至 1000/300 轮动 + 国债底仓的水平（~5%）。
2. **系统性熊市只能"躲"不能"赚"**：纯多头框架下 2022 式全面下跌只有防守资产 2.6% 的缓冲，-15~-20% 的年度亏损会重现。
3. **样本量有限**：ETF 窗口 9.8 年、含约 2 个牛熊循环；策略族的统计置信中等，非"证明了"而是"未被证伪"。
4. **512100 早期溢价**：2017-2021 该 ETF 流动性差、溢价扩张，历史信号受益于此；现在日成交 20-30 亿、溢价稳定，但小资金外的规模需另行评估冲击成本。
5. **成本假设保守方向**：ETF 实际免印花税/过户费而模型照收，结果偏保守；510300 分红未计入（~1%/年，同样保守）。
6. **数据缺口**：指数数据始于 2014-10（东财/新浪均如此），更长历史的代理回测只能用 000905 等近似，本研究未做。
