# SKILL: 实验对比与策略迭代

目标：让 Agent 用实验追踪做有依据的策略改进，而不是凭印象改参数。

## 核心循环

```
list_experiments(limit=20)
  → 挑出同策略不同参数（或不同策略同区间）的 run_id
    → compare_experiments(run_ids=[...])
      → 读差异 → 形成假设 → 只改一个变量 → run_backtest → 回到开头
```

## 怎么读对比表

指标列含义与陷阱：

| 指标 | 含义 | 陷阱 |
|------|------|------|
| annual_return | 年化收益（几何） | 短区间年化会被放大 |
| sharpe | 年化收益/年化波动 | 收益平稳的策略才可信；<0.5 基本不可用 |
| max_drawdown | 最大回撤 | 必须结合年化看（卡玛 = 年化/\|回撤\|） |
| trade_win_rate | 平仓交易胜率 | 趋势策略 30-40% 是常态，别拿它否决策略 |
| profit_factor | 总盈利/总亏损 | >1.3 才有继续优化的价值 |
| annual_turnover | 年化换手 | 高换手 + 低超额 = 费用吃掉收益 |
| excess_annual_return | 相对基准年化 | 评估策略的最终标准 |

## 实验纪律

1. **单变量原则**：两次实验只差一个参数/一处逻辑，否则对比无意义；
2. **实验命名带信息**：`双均线-fast10` 优于 `test2`；
3. **控制数据版本**：对比的实验应基于同一数据快照（get_experiment 看 data_snapshot）；
4. **防过拟合**：
   - 同一组参数换 2-3 个不重叠区间验证；
   - 换 1-2 个同类标的验证；
   - 参数敏感性：最优参数附近的邻居参数表现不应断崖式变差；
5. **费用意识**：A股双边成本约 0.15%（佣金+印花税+过户+滑点），策略年换手 1000% 意味着每年先亏 1.5%。

## 产物引用

每次实验的完整数据在 `get_experiment(run_id).artifacts_dir` 下：
- `result.json`：完整指标、逐日净值、全部成交与拒单（机器读）；
- `report.md`：人读报告；
- `trades.csv` / `nav.csv`：明细。

需要逐笔分析时直接读这些文件，不要试图让工具返回大表。
