# SKILL: 数据更新流程

目标：让 Agent 正确地把行情数据落到本地并保证可复现。

## 决策树

1. `get_data_overview` 看现有数据；
2. 需要新数据 → `fetch_bars`；
3. 做实验前 → 创建数据快照（`srq data snapshot create <tag>`，或提醒用户执行）。

## fetch_bars 用法

```
fetch_bars(symbols=["000001.SZ", "510300.SH"], start="2023-01-01", end="2026-09-08")
```

- **增量幂等**：重复调用只补缺口，不产生重复行；
- **start 建议显式给**：不传时走增量续拉（本地无数据则从 1990 年全量拉，慢）；
- **回测 prep**：回测起点往前留 ≥250 个交易日（warmup），即 start ≈ 回测起点 - 15 个月；
- 返回摘要含每个符号在本地库中的总行数与覆盖区间；
- 复权因子自动获取（东财主通道失败自动切新浪）。

## 交易日历

```
get_trading_calendar(update=true)   # 首次使用/年末更新
```
回测引擎依赖日历切分交易日；日历缺失时报 NO_DATA 并提示更新。

## 数据快照（可复现的关键）

数据每天都会变（新 bar、复权因子修正）。严肃实验前创建快照：

```
srq data snapshot create snap-20260908     # CLI 命令，近零拷贝
```

- 快照只读；回测结果会记录所用快照名，复现实验 = 指定同一快照；
- 不要往快照里写数据（会被拒绝）。

## 数据口径备忘

- 价格：**原始价 + 复权因子**（不做前复权落库），hfq = close × adj_factor；
- volume 单位：手（股票与期货均如此）；amount 单位：元；
- pre_close 为除权后口径（与交易所一致）；
- 指数/期货 adj_factor 恒为 1；新浪回退通道的 ETF 因子为 NaN。
